# 🔍 Project Workflow

Each major project will generally follow this process:

### 1. Define the Problem

Identify the business or analytical question that needs to be answered.

### 2. Understand the Data

Inspect:

- Number of rows and columns
- Data types
- Missing values
- Duplicate records
- Outliers
- Data distributions

### 3. Clean the Data

Handle:

- Missing values
- Duplicate records
- Incorrect data types
- Invalid values
- Inconsistent categories
- Outliers where appropriate

### 4. Exploratory Data Analysis

Use Python to investigate:

- Trends
- Relationships
- Distributions
- Patterns
- Anomalies
- Key metrics

### 5. Visualization

Create charts and visualizations to communicate important findings.

### 6. Extract Insights

Translate analytical results into meaningful observations.

### 7. Business Recommendations

Where appropriate, convert the findings into actionable recommendations.
